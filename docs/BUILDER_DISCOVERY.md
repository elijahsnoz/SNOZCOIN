# Builder Discovery Resources

## 🔍 Find Active Stacks/Bitcoin Builders

### GitHub Search Queries
Use these searches to find active developers:

1. **Clarity developers:**
   ```
   https://github.com/search?q=language%3Aclarity&type=repositories&s=updated
   ```

2. **Stacks projects (recently updated):**
   ```
   https://github.com/search?q=stacks+clarity&type=repositories&s=updated
   ```

3. **Contributors to Stacks core:**
   ```
   https://github.com/stacks-network/stacks-core/graphs/contributors
   ```
